❓ Issue 1: Why Are Some Countries Blank?

🔍 Root Causes

  1. Country Name Mismatch (MOST COMMON)

    The TopoJSON file and CSV data use different country names:

    • TopoJSON: "Congo" or "Democratic Republic of the Congo"
    • CSV: "Congo (Kinshasa)"
    • Result: lookup fails → no color assigned → appears white
  2. Missing Data

    The country exists in TopoJSON but has no matching record in the CSV file.

  3. Null Values

    The data exists but the value field is empty/null.

The Lookup Transform:
Vega-Lite tries to match: properties.NAME (TopoJSON) = Country (CSV)
When there's no match, the field returns null → color encoding skips it

✅ Best Solutions

1. Fix Data Mapping
Create a name matching table to resolve mismatches
2. Highlight Missing Data
Use conditional coloring (light gray for null)
3. Add Tooltips
Explain why data is missing
4. Use Color Condition
Different color for "no data" vs "zero cases"

Implementation Example

"color": { "condition": { "test": "datum.Active == null", "value": "#d3d3d3" // Light gray }, "field": "Active Cases", "type": "quantitative", "scale": {"type": "log"} }
✅ See the improved version above!
Gray countries now clearly indicate "No data available"

❓ Issue 2: Same Color for Neighboring Countries

🎨 Why Is This a Problem?

  • Visual Confusion: Impossible to see boundaries between similar-colored regions
  • Geographic Loss: Countries blend together; borders disappear visually
  • Analytical Difficulty: Hard to identify specific regions or compare neighbors
  • Choropleth Limitation: Continuous scales naturally produce similar colors for similar values

Why it happens: When adjacent countries have COVID cases in the same range (e.g., both have 5,000-10,000 cases), they get the same color shade, making it impossible to visually separate them on the map.

🔧 Solutions & Trade-offs

Solution Effort Effectiveness Best For
Add Darker Borders
(strokeWidth: 1.5)		 ⭐ Very Easy ⭐⭐ Moderate Quick fix; preserves data

🏆 Recommended: Binned Colors (Solution 3)

The binned version above uses discrete categories instead of continuous color:

  • ✅ Clear visual separation between neighboring countries
  • ✅ Easy to understand (0-1K, 1K-5K, 5K-20K, etc.)
  • ✅ Still shows meaningful patterns
  • ✅ Only loses minor precision
  • ✅ Works well for categorical data

Implementation Comparison

Continuous Colors (Original)

"scale": {"type": "log"}
Problems:
• Too many similar shades
• Hard to distinguish neighbors
• Precise but unclear

Binned Colors (Solution 3)

"type": "nominal", "domain": ["0-1K", "1K-5K", ...], "range": ["#f7fbff", "#c6dbef", ...]
Benefits:
• Distinct color for each bin
• Clear country boundaries
• Easy to read and understand

📋 Summary: Which Solution to Use?

🎯 For Your COVID-19 Choropleth Map

Best Approach (Recommended):

  1. Use binned colors (Solution 3) to fix the neighboring countries problem
  2. Add conditional gray coloring for missing data (from Solution 1)
  3. Combine with white borders to enhance clarity
  4. Add informative tooltips explaining no-data countries

This gives you the best balance of clarity, accuracy, and insight.

Teaching Points to Discuss

  • Data Quality: Always check if country names match between datasets
  • Visual Encoding: Color is powerful but has limitations with continuous data
  • Design Trade-offs: Binning loses precision but gains clarity
  • Accessibility: Consider colorblind users (viridis is better than blues)
  • Cognitive Load: Viewers can distinguish ~5-7 colors easily, not 50+
